# S.T.A.T.S (Synchronized Trophy & Achievement Tracking System)

A full-stack gaming dashboard that aggregates and tracks progression data across a multitude of games. Built with a responsive, glassmorphic UI, this application automates the retrieval of roadmaps, guides and player statistics.

## Features
* **Automated Web Scraping:** Utilizes Puppeteer to navigate pages and extract multi-page HTML guides.
* **Custom Caching Engine:** Implements a RAM-based cache and MongoDB storage to minimize redundant network request and manage strict memory restraints.
* **Dynamic DOM Manipulation:** Injects interactive state-tracking directly into third-party scrapes HTML data.

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript 
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas
* **Automation:** Puppeteer
